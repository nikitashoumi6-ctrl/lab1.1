# Лабораторная работа 1

# Описание
Реализовано 7 заданий по темам: целые числа и переполнение, вещественная арифметика, 
побитовые операции, работа со строками, 
одномерные и многомерные массивы, методы (перегрузка, varargs, рекурсия) и консольное меню для выбора задания.

# Структура проекта
src/ru/university/lab1/ — тут весь код
Main.java — точка входа, меню
task1...task7 — пакеты с заданиями, в каждом классе есть метод run()

# Как запустить
# Через скрипт
В корне проекта есть build.bat. Запуская его — он компилирует всё и собирает jar. Потом:
java -jar app.jar

# Вручную
javac -d out src/ru/university/lab1/Main.java
jar cfm app.jar manifest.mf -C out .
java -jar app.jar
